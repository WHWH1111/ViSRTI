# Data and Software Availability

The curated positive- and negative-ionization datasets used for NORMAN-label approximation and evaluation are available in machine-readable CSV format in the [ViSRTI repository](https://github.com/WHWH1111/ViSRTI). The files `data/MMF-3/MMF_GNN_pos.csv` and `data/MMF-3/MMF_GNN_neg.csv` contain molecular structures, the precomputed NORMAN target fields `Pred_RTI_Positive_ESI` and `Pred_RTI_Negative_ESI`, and auxiliary molecular descriptors. These targets are NORMAN predictions, not experimental RTI measurements. The filtering and preprocessing procedures are described in the manuscript. Source attribution, the CC BY 4.0 data terms, and the unrecorded exact NORMAN export version are documented in `DATA_ATTRIBUTION.md`.

The repository provides the fixed random assignments in `data/splits/random/`, scaffold holdout assignments in `data/MMF-3/MMF_GNN_pos/` and `data/MMF-3/MMF_GNN_neg/`, and five-fold scaffold assignments in the corresponding `_5/` directories. Scaffold holdout splitting uses a 90% development pool and 10% test subset, followed by a 90:10 scaffold split of the development pool; the seed is 1234. Split manifests record source-file hashes, sample counts, and scaffold overlap checks. Baseline and feature-fusion results are under `results/baseline_random_seed1234/` and `results/feature_fusion_random_seed1234/`. Final-model fixed-test predictions, fold-level and pooled out-of-fold predictions, category metrics, and figure source data are under `results/final_masked_models_seed1234/`, `results/final_masked_scaffold_seed1234/`, and `results/figure_source_data/`.

Supporting Information Tables S1 and S2 describe the 21 laboratory calibration standards and the separate BaP/BeP case compounds. This repository does not include the experimental inputs or a recalculated RT–RTI fit for the final GP/GPT models. The 21 standards and two case compounds do not constitute an independent experimental RTI test set.

Source code for preprocessing, training, prediction, evaluation, and SHAP analysis, together with the two selected final-model checkpoints, is available in the same repository. The supported software environment is specified in `environment.yml`, and the execution order is explained in `docs/代码导览.md`. Baseline predictions and metrics are provided as CSV files; baseline checkpoints and graph caches are not included, so fresh baseline inference requires retraining. The K/M and Supporting Information comparison requires the original external workbooks. Numerical reproduction uses the released data, recorded split assignments and training parameters.
