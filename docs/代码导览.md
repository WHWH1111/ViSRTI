# 代码导览

这个项目做的是学习 NORMAN 已预测的 RTI。输入是 SMILES 和相应的辅助特征，输出是模型预测 RTI；不是拿实验 RTI 直接训练。平时只想预测，不用重新训练。

## 拿到项目以后怎么走

1. 按根目录 `environment.yml` 建环境，运行 README 的四个快速测试。
2. 看 `data/MMF-3/MMF_GNN_pos.csv`、`MMF_GNN_neg.csv`。正、负模式各一份，目标列分别是 `Pred_RTI_Positive_ESI`、`Pred_RTI_Negative_ESI`。`data/splits/random/` 是原固定随机划分；`data/MMF-3/MMF_GNN_*/` 是 scaffold holdout；`*_5/` 是 scaffold 五折，不能混用。
3. 只要预测，就运行 `predict_visnet_v2.py`，指定对应模式的 `checkpoints/` 权重与参数文件。输出进 `outputs/`。
4. 要从头核对特征融合，运行 `scripts/run_feature_fusion_reproduction.ps1`。它依次训练 G、GP、GPT、GPTC，生成八个实验的配置、权重、预测和指标。这一步需要 GPU，不能把已发布的 `results/` 当成运行目录。
5. 再运行 `scripts/run_gp_gpt_masking.py`，针对正 GP、负 GPT 在开发集排序和逐步掩码。开发集 MAE 决定保留哪些特征。随后运行 `scripts/run_final_model_updates.py` 生成固定测试集分析，并由它调用 `scripts/run_selected_model_scaffold_cv.ps1` 做固定配置的 scaffold 五折。新结果写入 `outputs/`。实验 RT–RTI 校准还需要单独提供经确认的标准品输入。

如果只是查看论文结果，图 2 的数值在 `results/baseline_random_seed1234/` 和 `results/feature_fusion_random_seed1234/`；图 3–5 与图 S5 的中文绘图 CSV 在 `results/figure_source_data/`，矢量图在 `results/figures/`。无须先跑训练。`results/` 是已报告结果，`outputs/` 是新计算产生的文件。

## 根目录的 Python 文件

| 文件 | 用途 |
| --- | --- |
| `train_visnet_v2.py` | 单次 ViSRTI 训练，指定模式、特征层级、划分及掩码。 |
| `train_visnet_v2_5.py` | 五折训练入口，由 scaffold 运行脚本按折调用；不带参数时只显示帮助。 |
| `predict_visnet_v2.py` | 读取权重、训练参数和输入 CSV，输出逐样本 RTI 预测；至少两条且全部有标签时才计算评价指标。 |
| `train_baselines.py` | 训练 GNN-RT、GIN 和 SMILES-BiLSTM 对照模型。 |
| `preprocess.py` | SMILES、分子图和特征预处理函数，供训练与预测调用。 |

## 结果计算脚本

`scripts/` 里大多数 `.py` 是某一步的计算或出图脚本，不需要逐个手动执行。下面列出各自负责的产物。

| 文件 | 用途 |
| --- | --- |
| `scripts/run_gp_gpt_masking.py` | 调度正 GP、负 GPT 的开发集 SHAP 与逐步掩码。 |
| `scripts/run_final_model_updates.py` | 串行生成最终测试分析、scaffold 五折和交付数据。 |
| `scripts/data-val/aggregate_baseline_results.py` | 汇总基线预测和指标；完整重做还需原始 K/M 表及补充材料。 |
| `scripts/data-val/aggregate_feature_fusion_results.py` | 汇总八个特征融合实验的预测与四项指标。 |
| `scripts/data-val/aggregate_scaffold_results.py` | 合并每折预测，计算折指标、合并折外指标和类别结果。 |
| `scripts/data-val/analyze_gp_gpt_masking.py` | 计算辅助特征 SHAP 与单步掩码候选。 |
| `scripts/data-val/build_selected_model_fixed_split_results.py` | 图 S5 与类别分析共用的图表计算函数。 |
| `scripts/data-val/calculate_metrics.py` | 从预测文件独立重算 R²、MAE、RMSE、PCC 等指标。 |
| `scripts/data-val/evaluate_final_masked_models.py` | 按指定 GP/GPT 候选及开发集掩码停止规则冻结配置，计算固定测试集预测和 SHAP。 |
| `scripts/data-val/package_final_model_results.py` | 将最终分析的图表源数据整理到交付目录。 |
| `scripts/data-val/predict_calibration_samples.py` | 在标准品身份、特征和模式名单确认后做 RTI 预测与校准；本仓库不附这些实验输入。 |
| `scripts/data-val/verify_scaffold_splits.py` | 检查 holdout 和五折样本数及 scaffold 交集。 |
| `scripts/plt/compose_figure2.py` | 拼接图 2 的基线和融合分图。 |
| `scripts/plt/plot_baseline_violin.py` | 绘制基线性能分布。 |
| `scripts/plt/plot_calibration_results.py` | 用真实标准品结果绘制 RT–RTI 校准图。 |
| `scripts/plt/plot_final_masked_models.py` | 绘制最终图 3、图 4 和图 S5。 |
| `scripts/plt/plot_gp_gpt_masking.py` | 绘制 GP/GPT 掩码过程图。 |
| `scripts/plt/plot_test_metrics_bar_line.py` | 绘制 G、GP、GPT、GPTC 四组测试指标。 |

## 测试文件

这些文件不生成论文结果，运行 `python -m pytest tests -q` 即可，不需要逐个执行。

| 文件 | 检查内容 |
| --- | --- |
| `tests/test_model_smoke.py` | 模型能否在 CPU 上构建，输出头是否被正确训练。 |
| `tests/test_etkdg_randomness.py` | 分子构象生成的随机性与固定种子。 |
| `tests/test_scaffold_split.py` | scaffold 划分是否可复现、无交集，随机划分是否与原流程一致。 |
| `tests/test_metrics_cli.py` | 指标脚本能否读取单份预测表。 |
| `tests/test_plot_cli.py` | 特征融合画图脚本能否生成文件。 |
| `tests/test_prediction_unlabeled.py` | 无 RTI 目标列时只输出预测，不生成虚假的评价指标。 |
| `tests/test_gp_gpt_masking.py` | 开发集 SHAP、掩码停止规则，以及缓存预测的一致性。 |
| `tests/test_final_masked_evaluation.py` | 最终配置冻结、预测来源与指标选择规则。 |
| `tests/test_final_masked_figures.py` | 图 3、图 4 的特征列、样本、SHAP 与指标是否对齐。 |
| `tests/test_final_update_controller.py` | 分阶段运行、断点续跑与进程锁。 |
| `tests/test_selected_scaffold_plan.py` | 五折命令是否使用冻结的 GP/GPT 配置和掩码。 |
| `tests/test_aggregate_scaffold_results.py` | 类别统计是否只使用各样本的一条折外预测。 |

## 结果口径

图 2 使用固定随机测试集。图 3 的柱高是固定测试集一次性计算的四项指标，没有 Bootstrap 或误差棒。图 5 分别报告五折指标的均值和合并折外预测的指标，两个数值口径不能混用。正模式最终为 GP，去掉 Koc 和 LogP；负模式 GPT 的首次删除使开发集 MAE 变差，保留全部辅助特征。GP/GPT 候选是在看过早期测试结果后确定的；开发集 MAE 只决定这两个候选内部的掩码步骤。
